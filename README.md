# Divine Branding — Client & Project Manager

A simple, modern project board for Divine Branding.

## Status columns
- Create Design
- Start Printing
- Done

There are **no percentages**.

## Project fields
- Client name
- Vehicle: Van, Truck, Box truck, Door graphics

Projects are saved automatically in the browser using local storage.

## Run it
Open `index.html` on a phone or computer in a browser.

## GitHub
Create a GitHub repository and upload `index.html`. GitHub Pages can publish it as a website.
